Run `bash tests/run-tests.sh` and `bash tests/test-integrations.sh` from the repository root. The smoke suite validates shell syntax, allowlisted distribution routing invariants, dependency version gates, conservative repository policy, backup metadata, scoped Quickshell control, and removed legacy Fedora wrappers. Integration fixtures run Hyprland merge using a mocked Hyprland binary and check idempotency, user-hook preservation, version rejection, and symlink-safe config writes. These are mocked shell tests; they do not perform package transactions or launch a graphical session.
